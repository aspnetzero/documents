405 Method Not Allowed — the WebDAV signature
A DELETE request never reaches your controller. IIS answers it first.
Request
DELETE /api/users/42 HTTP/1.1 Host: api.example.com Authorization: Bearer eyJhbGciOi… Origin: https://app.example.com
Response
HTTP/1.1 405 Method Not Allowed Allow: GET, HEAD, OPTIONS, TRACE Server: Microsoft-IIS/10.0 (no Access-Control-Allow-Origin)
Read the Allow header. PUT and DELETE are missing because the WebDAV module claimed those verbs before your application saw the request. And because the response carries no Access-Control-Allow-Origin header, the browser reports it in the console as a CORS error — which sends most developers off to fix the wrong thing.
