## Used Libraries & Frameworks

Many open source frameworks and libraries are used to build ASP.NET Zero
project. Here's the list of the main libraries used by the Angular UI:

### Core

- [Angular](https://angular.dev/)
- [Angular CLI](https://angular.dev/tools/cli)
- [Typescript](http://typescriptlang.org/)
- [RxJS](https://rxjs.dev/)
- [abp-ng2-module](https://github.com/aspnetboilerplate/abp-ng2-module)
- [SignalR](https://learn.microsoft.com/en-us/aspnet/core/signalr/introduction)

### UI & Theme

- [Metronic Theme](https://keenthemes.com/metronic/)
- [Twitter Bootstrap](https://getbootstrap.com/)
- [Ngx Bootstrap](https://github.com/valor-software/ngx-bootstrap)
- [ng-zorro-antd](https://ng.ant.design/)
- [Angular CDK](https://material.angular.dev/cdk/categories)
- [angular-gridster2](https://github.com/tiberiuzuld/angular-gridster2)
- [animate.css](https://github.com/animate-css/animate.css)
- [Famfamfam flags](https://github.com/legacy-icons/famfamfam-flags/)
- [Simple Line Icons](http://thesabbir.github.io/simple-line-icons/)
- [Perfect Scrollbar](https://github.com/mdbootstrap/perfect-scrollbar)
- [ngx-scrollbar](https://github.com/MurhafSousli/ngx-scrollbar)
- [ngx-spinner](https://github.com/Napster2210/ngx-spinner)
- [SweetAlert2](https://github.com/sweetalert2/sweetalert2)

### Forms & Editors

- [angular-imask](https://imask.js.org/)
- [Quill](https://quilljs.com/)
- [Monaco Editor](https://microsoft.github.io/monaco-editor/) and [ngx-monaco-editor-v2](https://github.com/materiahq/ngx-monaco-editor)
- [ngx-image-cropper](https://github.com/Mawi137/ngx-image-cropper)
- [ng-recaptcha-2](https://github.com/kolkov/ng-recaptcha)
- [zxcvbn-ts](https://zxcvbn-ts.github.io/zxcvbn/) (password strength)

### Charts

- [ngx-charts](https://github.com/swimlane/ngx-charts)
- [Chart.js](https://www.chartjs.org/)
- [FullCalendar](https://fullcalendar.io/)

### Authentication

- [angular-oauth2-oidc](https://github.com/manfredsteyer/angular-oauth2-oidc)
- [MSAL for Angular](https://github.com/AzureAD/microsoft-authentication-library-for-js)

### Utilities

- [LocalForage](https://github.com/localForage/localForage)
- [Luxon](https://moment.github.io/luxon/)
- [Lodash-es](https://lodash.com/)
- [js-cookie](https://github.com/js-cookie/js-cookie)
- [push.js](https://github.com/Nickersoft/push.js)
- [rtl-detect](https://github.com/shadiabuhilal/rtl-detect)
- [cookieconsent](https://github.com/osano/cookieconsent)
- [aspnetzero-web-resources](https://www.npmjs.com/package/aspnetzero-web-resources)

### Build & Test

- [pnpm](https://pnpm.io/)
- [Gulp](https://gulpjs.com/) (dynamic asset bundling)
- [NSwag](https://github.com/RicoSuter/NSwag) (service proxy generation)
- [ESLint](https://eslint.org/) and [Prettier](https://prettier.io/)
- [Karma](https://karma-runner.github.io/) and [Jasmine](https://jasmine.github.io/)
- [Playwright](https://playwright.dev/) (see [UI Testing](Playwright-UI-Testing-Angular))

> The authoritative list is always the `dependencies` and `devDependencies` sections of `angular/package.json` in your own project.
